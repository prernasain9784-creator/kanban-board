# PROMPT.md – Kanban Task Management Project

## 1. Project Overview

The main purpose of this project is to help users organize, manage, track, and monitor their daily tasks through three different columns: To Do, In Progress, and Done.

## 2. Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS
- LocalStorage
- @dnd-kit/core

## 3. Phase 1 – Mandatory Features (P0)

### Three Columns
Create three columns:
- To Do
- In Progress
- Done

### Add Task
Allow users to create new tasks and add them to the To Do column.

### Delete Task
Provide an option to delete tasks.

### Move Task
Allow users to move tasks between different columns.

## 4. Phase 2 – Priority Features (P1)

### Inline Editing
Allow users to edit task titles by clicking on them.

### Priority System
Add three priority levels:
- High Priority – Red
- Medium Priority – Yellow
- Low Priority – Green

### LocalStorage
Save tasks in browser LocalStorage so that tasks remain available even after refreshing the page.

## 5. Phase 3 – Advanced Features (P2)

### Drag and Drop
Implement drag-and-drop functionality using the @dnd-kit/core library.

Users should be able to drag tasks from one column to another.

### Global Search
Add a search bar that allows users to search and filter tasks in real time across all three columns.

## 6. User Interface

- Create a clean and modern dashboard.
- Use a professional dark theme.
- Make the application responsive.
- Use proper spacing, colors, and typography.
- Provide a simple and user-friendly interface.

## 7. Expected Output

The final application should allow users to:

- Add new tasks.
- Edit existing tasks.
- Delete tasks.
- Set task priorities.
- Move tasks between columns.
- Drag and drop tasks.
- Search tasks instantly.
- Save tasks using LocalStorage.
- Access the application on desktop and mobile devices.

## 8. Final Goal

Develop a fully functional and responsive Kanban Task Management Board that successfully implements all the requirements of Phase 1, Phase 2, and Phase 3.
